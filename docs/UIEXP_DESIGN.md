# UIEXP design (lane L2): Expert Part / Assembly / Engineering on a wide window

Same colours (Tok: graphite panel, amber accent, sky focus), same app, less to read.

## The grid at 1920x1080 (scale rule: design here, reflow down)
- Top: the ribbon bar as before, but on Part and Assembly it holds only the mode buttons (What to build, Part, Easy); the tools moved to the rail.
- Left: **tool rail** (96 px), icons grouped by task with a 12 px caption: Part = SKETCH, CREATE, MODIFY, CHECK; Assembly = ASSEMBLE, CHECK, DELIVER.
  Two columns of 40x36 buttons. The common tools show; the rarer ones sit under a "..." button per group (a popup of icon + name).
  Part shows 17 buttons for 29 functions, Assembly 17 for 19; every function still exists (docs/uiexp/functions_old.json).
- Then the Part browser / Assembly Add-part list (they start right of the rail: `nav_clear_rect` adds the rail's width).
- Right: the contextual inspector (the Extrude / Fillet dialog, the Assembly list and numbers, the Fits panel), unchanged but with the buttons the rail carries removed.
- Bottom: the Part timeline, say-line, page bar. Viewport share of the window: 70 to 81 %.
- Rail buttons are proxies: pressing one presses the original tool button (same name, tooltip source, undo step, key); a disabled / pressed original shows on the rail.
  Tooltips go through TooltipFit like every other control.

## Reflow rule
`UiExpShell.WIDE` = 1600x900. At or above it the rail replaces the ribbon / panel tool rows. Below it (1366x768, 1280x720) the compact ribbon and panel rows stay
exactly as before, so 1280x720 tests and layouts are untouched. A 4K window (3840x2160 at UI size 150 %) is the same layout scaled by the existing UI size
setting (`SCALES`, `auto_scale`); the rail is in layout pixels.

## Window rule
`UiExpShell.fit_window` (called once from `main._ready` on a real run, never in a test): the client size is shrunk to the usable rect of the window's screen
(`DisplayServer.screen_get_usable_rect`) minus the decorations, the position pulled inside it, `min_size` lowered if the screen is smaller than 1280x720.

## Other fixes
- Panels of Part / Assembly start under the ribbon bar (`UiExpShell.top_y` in `nav_clear_rect`); the warning strip's top row follows the bar (`_top_y`).
- The Assembly panel's parts list gives up height so the panel never runs under the page bar.
- Part labels under 12 px raised to 12 (TIMELINE, Suppress, Delete step, warning help / muted title).

## Icons
77 original SVG drawings, `assets/icons/uiexp/*.svg`, generated by `tools/uiexp_icons.py` (24 px grid, 2 px stroke, round caps; body #ECEFF4, one amber #FFC733 part).
`UiExpIcons.tex(id, px)` rasterises them at run time (no import step) and swaps the two colours in the light theme. Contact sheet: `docs/uiexp/icons.png`.

## Bars (tests/uiexp_test.gd, registered `uiexp:w`)
OUTSIDE, OVERLAP, REACH, ICONS, WINDOW, VIEW, COUNT, each with a planted control that must fail; see the header of the test.
